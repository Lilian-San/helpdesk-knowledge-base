# What is IT troubleshooting?

It is a process of diagnosing and fixing issues with hardware, software or networks.

IT Troubleshooting is important as it helps ensures systems run smoothly,  minimises downtime, supports SLAs and keeps operations efficient.

1. Identify the problem and gather information.
2. Establish a hypothesis of root cause. 
3. Test the hypothesis to determine the cause. 
4. Establish am action plan and implement the solution.
5. Verify full functionality. 
6. Document findings. is this best practice trouble shooting

## Example

### 1. Identify the Problem and gather information
User reported that files were transferring very slowly between network locations.  
  
### 2. Establish a Hypothesis of the Root Cause  
Possible causes included a network issue, faulty network cable, file server issue or workstation fault.  
  
### 3. Test the Hypothesis  
Confirmed the issue only affected one user. Tested file transfers from another workstation and inspected network connectivity.  
  
### 4. Establish an Action Plan and Implement the Solution  
Replaced the network cable connected to the user's workstation.  
  
### 5. Verify Full Functionality  
File transfer speeds returned to normal and the user confirmed the issue was resolved.  
  
### 6. Document Findings  
Root cause was identified as a faulty network cable causing poor network performance.
